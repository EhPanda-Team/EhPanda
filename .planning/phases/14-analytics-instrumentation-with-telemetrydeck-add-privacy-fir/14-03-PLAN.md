<objective>
Build the closed vocabulary types that every analytics payload value is drawn from, and the two audited content-reduction types (`TagNamespaceCounts`, `SearchShape`) that turn app-domain content into that vocabulary.

Purpose: this is the D-09 type wall in concrete form. It is authored before `AnalyticsSignal` (plan 14-05) so the signal enum has nothing but closed types to reach for — a contributor adding a case later cannot express a free-form payload because no such type exists in the module.
Output: four vocabulary/reduction source files plus exhaustive unit suites, including the negative tests that prove no content text survives a reduction.
</objective>

    - `public init(keyword: String)` derives exactly four values and stores nothing else:
      - `wordCount: CountBucket` — from the count of whitespace-separated non-empty tokens.
      - `usedTagSyntax: Bool` — true when the keyword contains a namespace-qualified term (a colon-separated prefix matching a known `TagNamespace` raw value or its abbreviation, per `TagNamespace.abbreviations`).

    - The type stores **no** keyword text. `Equatable`, `Sendable`.
    - An empty keyword yields `wordCount == .zero`, `usedTagSyntax == false`, `keywordLength == 0`.
  </behavior>
