<objective>
Instrument `DetailFeature`: tag taps, download start / retry / delete, and the detail-search screen's panels.

Purpose: the tag namespace D-07 permits is known in the view but is currently dropped before the reducer sees it — the reducer only receives an assembled search keyword. Recovering the namespace by parsing that keyword back apart would mean the tag text entering the analytics path, which D-06 forbids. This plan threads the namespace through the action instead, which is both safer and simpler.
Output: six emission sites, one widened callback, one new reducer action, and their `TestStore` proofs.
</objective>
