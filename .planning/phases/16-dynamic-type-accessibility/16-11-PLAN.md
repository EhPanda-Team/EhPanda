Purpose: the owner fixes; the agent proves each fix against both halves of D-15 and keeps the verdict table truthful.
Output: `16-SWEEP.md` with no `open` finding, no `re-verify` row, every D-13 row dispositioned, a per-batch re-verification log, and the owner's `ROUND1-CLEAR`.
</objective>
