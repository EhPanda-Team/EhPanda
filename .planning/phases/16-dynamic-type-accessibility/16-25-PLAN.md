**Shared xcodebuild lock.** Every `xcodebuild` invocation, including builds, follows these steps:
1. Wait until `mkdir "$LOCK"` succeeds.
2. Wait until `pgrep -x xcodebuild` prints nothing.
3. Run exactly one `xcodebuild`.
4. `rmdir "$LOCK"` when it exits, also when it fails.

Never run two at once. Never kill an `xcodebuild`, a test runner or `testmanagerd` mid-launch. Output is buffered until exit, so a quiet log is not a hang.

**VoiceOver method (research § 1–3, re-validated in Task 1).**
1. Stream the log in the background: `xcrun simctl spawn <UDID> log stream --style compact --level debug --predicate 'process == "vot" AND subsystem == "com.apple.Accessibility"'`, to a file under `$WALK/transcripts/`.
2. Enable VoiceOver: `xcrun simctl spawn <UDID> defaults write com.apple.Accessibility VoiceOverTouchEnabled -bool true`, then `xcrun simctl spawn <UDID> launchctl start com.apple.VoiceOverTouch`.

3. Move focus with `sim-use ios key-combo --modifiers 224,226 --key <79 next | 80 previous | 81 down | 82 up> --device <UDID>`. Add Cmd (227) for the rotor: Cmd+Right cycles rotors, Cmd+Down steps through rotor items.

10. Disable VoiceOver by writing `false` and running `launchctl stop com.apple.VoiceOverTouch`.
