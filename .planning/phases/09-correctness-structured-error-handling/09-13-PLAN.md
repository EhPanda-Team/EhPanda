## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Asynchronous failure presentation -> assistive-technology input | A transient app event must remain perceivable and operable regardless of input speed or modality. |
| Toast UUID lifecycle -> host routing closure | Replacement, dismissal, and stale tasks must not replay or misroute an old ErrorInfo. |
