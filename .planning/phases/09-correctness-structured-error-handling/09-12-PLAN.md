## Artifacts this phase produces

This plan changes/creates:
- A route-aware gallery-failure `Context` factory that retains action/reason and a validated numeric gallery ID, but never a route token, image key, query, host, or full path.
- A `ContextKey` vocabulary with no generic raw-URL slot.
- Parameterized sanitizer tests for `/g/<gid>/<token>` and `/s/<key>/<gid>-<page>` plus PresentationFeature integration coverage.
