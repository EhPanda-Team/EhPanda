<objective>
Build the hermetic stub seam (D-06): a DEBUG-only launch-environment flag that registers a fixture-serving `URLProtocol` on `URLSession.shared` and overrides the clipboard dependency — extending the repo's `AppLaunchAutomation` env-seam precedent. Fixture content is served from a directory path the UI test runner passes (`EHPANDA_UITEST_FIXTURE_DIR`), so nothing test-only ships in release and no oversized literals enter Swift sources.

This plan also lands the second half of the app-side preparation: accessibility identifiers on the deep-link destination screens. Both halves are pure app-side metadata with no dependency on the UI-test harness, so they precede it — 13-08 arrives to find every hook it needs already in place.

Purpose: SC-2's foundation — the thing under test (parsing + routing) stays real; the network and clipboard become deterministic, and every destination is addressable without reading localized text.
Output: UITestSupport seam in AppFeature, armed from EhPandaApp.init, proven by in-process unit tests ahead of the UI harness (13-08), plus the identifier hooks 13-08/13-09/13-10 assert against.
</objective>
