## Info

### IN-01: An edit inside the prefill counts as "Details text beyond the prefill"

**File:** `AppPackage/Sources/DetailFeature/Moderation/ReportFormFeature.swift:194-199`
**Issue:** When Details no longer starts with the exact prefill, `hasDetailsBeyondPrefill` compares the whole field
with the prefill. Deleting one character of the prefill, with nothing typed, therefore enables Send Report. The
report the site receives is still the user's deliberate text and the comment reference, so nothing wrong is sent.
The C-13 rule ("text beyond the prefill") is just looser than written in this one case.
**Fix:** Optional. Require at least one non-whitespace character outside the longest common prefix with the prefill,
or accept the current behaviour as "the user edited the report".

### IN-02: The email check accepts spaces inside the address

**File:** `AppPackage/Sources/DetailFeature/Moderation/ReportFormFeature.swift:379-384`
**Issue:** `isPlausibleEmail("a b@c.d")` is `true`. DD-05 makes the check deliberately minimal ("the site does its own
check"), and the value is trimmed, so this only lets an obviously mistyped address reach the site, which then
rejects it. That shows as the failed alert, not as the inline "invalid email" footer.
**Fix:** Optional. Also reject any whitespace in `trimmedEmail`, and add one argument to
`anInvalidEmailFocusesTheFieldAndSendsNothing`.

### IN-03: Each presenter must remember to start the form's load

**File:** `AppPackage/Sources/DetailFeature/Comments/CommentsReducer.swift:151-154`,
`AppPackage/Sources/DetailFeature/DetailReducer+Actions.swift:76-79`
**Issue:** `ReportFormView` has no `.task`. The load starts only because each presenting reducer sends
`.destination(.presented(.reportForm(.task)))` right after setting the destination. Both presenters do this today,
and `CommentsReducerTests`/`CommentModerationReducerTests` pin it. A third presenter that forgot the line would
leave the form on its loading state for good (with the spinner after 0.3 s and no way forward but Close).
**Fix:** Optional. Add a shared helper on the moderation scope (e.g. `presentReportForm(_:)` returning the destination
plus the effect), or document the contract on `ReportFormFeature.Action.task`.
