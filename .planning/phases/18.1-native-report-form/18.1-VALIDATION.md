## Sampling Rate

- **After every task commit:** the touched module's FeatureTests on `$PHONE` (or the named UI test classes) and
  strict lint of the touched paths.
- **After every plan:** the touched modules' FeatureTests on `$PHONE` then `$PAD`.
- **Before `/gsd-verify-work`:** plan 18.1-05's gate: FeatureTests and UITests on both devices, 0 failures, 0
  Repetition nodes, strict no-cache lint 0 violations, both copy checks, the Release scan; then the agent-run live
  check.
- **Max feedback latency:** 300 s for a module run.
