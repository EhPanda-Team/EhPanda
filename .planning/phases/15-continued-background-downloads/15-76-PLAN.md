<objective>
Deliver the first owner-directed UAT follow-up (15-UAT.md § Deferred Follow-Ups, test 6, deferred 2026-08-08): "Rename the logs folder so its displayed name begins with an uppercase letter." The folder is user-visible in the Files app (`UIFileSharingEnabled` over `Documents`, App/Info.plist:170), named by `Defaults.FilePath.logs = "logs"` (AppPackage/Sources/AppTools/Defaults.swift:42) and consumed through `FileUtil.logsDirectoryURL` (AppTools/FileUtil.swift:4-6). Changing the constant alone would STRAND existing installs' logs in an invisible `logs` directory: iOS data volumes are case-sensitive APFS, so `logs` → `Logs` is a real rename requiring a one-time migration — while the simulator and dev Macs are typically case-insensitive, so the migration must be correct in both regimes.

Consumer enumeration with dispositions (all verified by grep this round — the complete set): `FileUtil.logsDirectoryURL` (derives from the constant — inherits), `LogsClient.swift:90/97/106/148` (all through FileUtil — inherit), `ApplicationClient.swift:49` `openFileApp` (builds a `shareddocuments://` URL from FileUtil — inherits), `AppPackage/Sources/AppTools/Defaults.swift:42` (the one change site). No other `"logs"` literal exists in App, AppPackage, or ShareExtension.

Purpose: the owner's follow-up closed without stranding a single existing install's logs.
Output: the renamed constant, a regime-complete one-time migration wired at launch, and piecewise tests per regime.
</objective>

## Artifacts this phase produces

- `Defaults.FilePath.logs` changed to `"Logs"` (Defaults.swift:42).
- New `AppPackage/Sources/AppTools/LogsDirectoryMigration.swift`: an enum (or caseless namespace) `LogsDirectoryMigration` with a parameterized entry `static func run(documentsURL: URL, fileManager: FileManager = .default) -> Outcome` — pure of process-global state so AppToolsTests can drive it against temp directories — plus an `Outcome` describing what happened (nothingToMigrate / renamed / merged(movedCount:skippedCount:) / failed(reason:)). Detection reads the LITERAL stored directory names via `contentsOfDirectory` of `documentsURL` (never `fileExists`, which lies on case-insensitive volumes about case variants).
- Collision disposition (decided, stated in the doc): when BOTH `logs` and `Logs` literally exist (case-sensitive volumes only), merge file-by-file from `logs` into `Logs`, skipping any file name that already exists in the destination (the existing file wins — run-log names embed date+count, so a collision means the same run file, and keeping the destination is deterministic); remove the emptied `logs` directory; leave any unmovable file in place (best-effort). When only `logs` exists on a case-insensitive volume (single directory entry stored lowercase), perform the case-only rename via `moveItem` (APFS supports case-only renames); if that fails on a given filesystem, fall back to a two-step move through a temporary sibling name. Failures never throw out: the outcome reports, the caller logs, and the app continues with whatever directory exists.
- Wiring in `AppDelegateReducer` (AppFeature): the migration runs from the launch path (`onLaunchFinish`'s `.run` effect). Because that effect is async, strict before-any-log-write ordering is NOT guaranteed and is NOT claimed; the design is race-tolerant instead: a log write racing the migration lazily creates `Logs` via `appendToRunFile`'s `createDirectory` (which reads the new constant), and the migration's both-exist merge regime then absorbs the legacy `logs` contents (on a case-insensitive volume the racing write lands inside the single case-blind directory and the case-only-rename regime covers it). The executor MUST carry this derivation into the SUMMARY. Wiring includes a `private let logger` at the top of the file per the Logger-placement rule (Logger+.swift is init-only) logging a non-`nothingToMigrate` outcome — no gallery-adjacent content is involved, so a plain public log of the outcome kind is fine.
- New `AppPackage/Tests/AppToolsTests/LogsDirectoryMigrationTests.swift`: regime-piecewise cases (see Task 1), each against its own temp directory.
