<objective>
Plan 15-20 changed the accounting basis and proved the completion path. This plan proves the other
departure paths, which is where the previous gap rounds in this phase went wrong: a fix scoped to the
branch the report named left the sibling branches open, and each round found one more.

Rule **D-G2-01**, decided and documented in 15-20: **a gallery that leaves the schedulable set by
pausing, deleting or being cancelled retires exactly the pages it had already finished — added to
both the numerator and the denominator — and its unfinished pages leave with it.** That rule is what
keeps a pause from pinning the card below one forever, and what keeps a delete from rewinding the
numerator. It is implemented as one formula over an observed membership map, so no production code
branches on *why* a gallery left; this plan is the evidence that the single formula actually behaves
correctly on each reason.

Three properties need coverage that the completion cases cannot give:

- **Pause.** The denominator must drop by the paused gallery's *unfinished* pages only. Dropping more
  would rewind the numerator; dropping less would keep work in the denominator that will never be
  done.
- **Delete.** The gallery's record is gone from the index, so the ledger cannot read a final count
  and must fall back to the last observation. The pushed pair must match the pause case exactly —
  same finished pages retired, same remaining work.
- **Rejoin.** A paused gallery resumed back into the queue is a real user action under D-07, and the
  ledger must release it as the live sum picks it up. Without that release the same pages are counted
  twice and the card claims more progress than exists.

Purpose: close the departure paths the device report did not exercise, so this gap does not refill.
Output: three regression cases driven through the coordinator's own primitives, plus a recorded
deliberate-break check that the suite is not passing vacuously.
</objective>
