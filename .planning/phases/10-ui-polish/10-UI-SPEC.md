# Phase 10 — UI Design Contract

> Visual and interaction contract for Phase 10 (UI Polish). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Contract nature: PARITY, not design.** This phase modernizes SwiftUI mechanisms in an existing, shipped app. The milestone forbids any visual redesign (REQUIREMENTS.md "Out of Scope"). There is no new palette, typography scale, component, or copy to invent. This contract LOCKS what must not change (appearance at default type size), what must change (Dynamic Type reflow, numeric-text treatment), and how change is proven (sim-use gates D-03/D-11). Web-oriented template sections are adapted to their SwiftUI equivalents; sections with no SwiftUI analogue are marked N/A rather than filled with invented content.
>
> Sources: 10-CONTEXT.md (D-01..D-12, owner decisions), 10-RESEARCH.md (grep-verified inventories, 2026-07-17), ROADMAP.md §Phase 10 (the 12 authoritative success criteria), repo CLAUDE.md + `.swiftlint.yml`.

## Spacing Scale

**N/A as a new scale — parity contract instead.** This phase introduces no spacing tokens and MUST NOT alter any existing spacing, padding, or metric value. The web template's 4px grid does not apply; the app's existing point values are the locked baseline.

| Rule | Contract |
|------|----------|
| Existing spacing/padding values | Preserved verbatim through every conversion (ZStack→overlay/background, Label, clipShape) |
| Composite sizing | `.overlay`/`.background` are sized to the modified view; a conversion that changes which child defines the composite size is FORBIDDEN — keep the `ZStack` (criterion 4 permits it) |
| Corner radii | Existing values preserved exactly: 15 (cards/thumbnails), 10, 5, 2, and computed `width / 3` (NewDawnView). `.rect` default corner style (`.circular`) matches the deprecated modifier — do NOT add `style: .continuous` |
| Masonry grid | 15pt fixed spacing, min cell width 185pt (Phase 2 contract) — untouched |
| Reflow-added layout (DT work) | New reflow constructs (`ViewThatFits`, wrapping, `@ScaledMetric`) must be **no-ops at default (`.large`) type size** — zero spacing/layout change at default size |

Exceptions: none.

## Typography

**No fixed pixel scale — Dynamic Type is the typography system.** Existing text styles are the locked baseline; the contract governs how text behaves across the DT range.

| Rule | Contract | Source |
|------|----------|--------|
| Text styles | Existing `.font(...)` text styles preserved at parity; no role/size/weight changes at default size | Parity constraint |
| Dynamic Type range | Every user-facing screen (including sheets) readable AND operable through the FULL range incl. AX sizes — no clipped essential text, no overlapping content, no unreachable controls | D-01, criterion 5 |
| Caps | **`dynamicTypeSize(...maxSize)` is FORBIDDEN everywhere** — currently 0 sites; must remain 0. No exceptions, not even compact chrome | D-02 (absolute) |
| Shrink-to-fit | Adding `.minimumScaleFactor` to "fix" DT breakage is forbidden (a cap in disguise). Remediation = reflow: `ViewThatFits`, wrapping, `ScrollView`, dropping fixed heights / `lineLimit(1)` | D-02 |
| Fixed-size fonts | The 7 `.font(.system(size:))` sites (ReadingViewComponents:268, HomeView+Sections:457, AlertView:112, DetailView+Subviews:62/104/144, DetailView+HeaderSection:210) do not scale with DT — remediate via text-style-relative sizing or `@ScaledMetric(relativeTo:)`, appearance-identical at default size | RESEARCH crit. 5 inventory |
| Risk sites | 33 `lineLimit(1)` + 35 fixed `frame(height:)` sites are the audit surface for AX5 breakage — fix by reflow only where breakage is observed; do not blanket-rewrite | RESEARCH crit. 5 inventory |
| Monospaced digits | See Numeric Text Contract below | D-04..D-06 |

## Color

**No palette — parity contract.** No color value changes anywhere; the only color-touching work is mechanism swaps at identical rendered output, plus the one owner-gated delta below.

| Role | Value | Contract |
|------|-------|----------|
| All surfaces/text/accents | Existing system colors (semantic UIKit/SwiftUI colors) | Unchanged. `foregroundColor`→`foregroundStyle` (43 sites) and `.accentColor(_:)`→`.tint(_:)` (27 sites) are pure mechanism swaps at identical appearance — diff-review tier (D-11) |
| Root tint | `.accentColor(.primary)` → `.tint(.primary)` at `RootView.swift:13` | Same value; spot-check tab-bar/link tinting |
| Static `Color.accentColor` | 3 sites (EhSettingView+Sections1:102, ControlPanel:380, LiveTextView:71,79) | NOT deprecated — leave untouched |
| Sheet-elevation grays (inSheet removal) | `systemGray4/5/6` selection logic, reproduced via `UIColor { traits in traits.userInterfaceLevel == .elevated ... }` dynamic provider | Recommended mechanism (RESEARCH crit. 6). **Known delta:** previously-unflagged sheets (QuickSearch, Filters, modal Detail) would newly resolve the elevated gray. The plan MUST state this delta explicitly and D-11 must spot-check one previously-unflagged sheet; fallback = explicit `Bool` init parameter if the owner rejects the delta |
| Optional tint trap | `CustomToolbarItem` (`ToolbarItems.swift:29`) passes `Optional<Color>`; `foregroundStyle` has no Optional overload | Restructure to conditional application (`if let`) at parity — never a force-unwrap or default color |

Accent reserved for: N/A — no accent-budget design; existing tint usage is preserved as-is.

## Numeric Text Contract (POLISH-01, D-04..D-06)

| Rule | Contract |
|------|----------|
| Pairing | `.monospacedDigit()` + `.contentTransition(.numericText())` applied **as a pair, always together** |
| Eligibility | ONLY values that visibly change on screen. Static one-off numbers get **neither** — an untreated static number is correct, not a coverage gap (verifier note) |
| D-05 set (must treat) | Reader current/total page (ControlPanel:170), download progress %/size (DownloadBadgeLabel:17, DownloadsView+Subviews), favorite/comment/rating/page/size counts on Detail (DetailView+Subviews:20-40), rating on tap (:104), cache size after clearing (GeneralSettingView:114), archive funds (ArchivesView:139), thread-limit slider (DownloadSettingView:15) + best-judgment additions |
| Exemplar | Copy `DownloadsView+Subviews.swift:179-186` verbatim as the pattern |
| Variant | `.numericText(value:)` for pure numbers where direction matters; plain `.numericText()` for mixed strings ("12.3 MB") |
| No jitter | The paired `monospacedDigit()` is the jitter guarantee (D-06); unanimated transitions are inert, which is acceptable |

|------|----------|
