## Owner decision: the owner supplies every marketing gallery ID (2026-10-07)

During 17-03 the executing agent declined to choose explicit-set galleries. It cannot
rule out sexualized depictions of minors on the source site without reviewing explicit
images. Asked how to proceed, the owner chose that the owner supplies the gallery IDs
for both sets ("兩組都由你提供 ID"). For 17-03 this narrows the 2026-10-02 delegation in
D-02, D-04 and D-05: the agent selects no real gallery for either set and browses no
candidates.

Consequences for this plan:

- T1 delivers `acquire-fixtures.py`, the `fixtures.py` validation, its tests, the ignore
  rule and documentation. Tests use synthetic responses and the repository's saved parser
  responses, with no network access.
- 17-03 acquires no real selection or asset. The T1 outcome "a versioned real provisional
  selection and assets exist locally" becomes an owner-input checkpoint. When the owner
  supplies gallery URLs, set assignments, scene slots and pages, the agent runs the
  acquisition with `selectionAuthority: owner`.
- T2 delivers `selection-review.py` and its tests. Its visual review of real content waits
  for the same input.
- Plans that consume `.capture/marketing/current` (17-04 onward) need this input before
  any step that depends on real content.

## Owner instruction: random provisional galleries (2026-10-07, later)

The owner has no time to choose galleries and asked the agent to pick the IDs at random
for both sets, with the nonexplicit set limited to the Non-H category ("非成人那個限定
non-h 裡面就好"). For the nonexplicit set this supersedes "the agent selects no real
gallery" in the decision above.

- Nonexplicit set: the agent samples Non-H galleries at random with a recorded seed and
  keeps the sampling record as evidence. Galleries tagged lolicon, shotacon or toddlercon
  are always excluded. The agent then reviews every cover, the flow gallery's previews and
  its reader pages visually and replaces any gallery that shows nudity, sexual suggestion,
  gore or photographs of real people. The selection is acquired with
  `selectionStatus: provisional` and `selectionAuthority: agent-delegated`.
- Explicit set: the agent does not select. Random selection from the explicit categories
  cannot exclude sexualized depictions of minors, which are common on the source site and
  not reliably tagged, and the agent would download explicit images it cannot inspect. The
  explicit set remains owner input; the tooling accepts it as a later selection version.
- The final selection for both sets remains the owner's at Phase 17 closure (17-21).
