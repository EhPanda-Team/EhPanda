# Phase 261126-0b9 Plan 01: Automate the AltStore PAL notarization submission Summary

Deploy now submits the AltStore PAL build for notarization from the same approved `app-marketplace` job: the signing material is removed right after the upload, then the job waits for App Store Connect to process the build, creates or reuses the Notarization version, fills What's New per localization from `ReleaseNotes/<version>.md` (no fallback), attaches the build and submits it, with the API key removed last.

## What was built

- **Trigger and caller (Task 1).** `marketplace-upload.yml` has exactly `workflow_call` and `workflow_dispatch`, each with one boolean `submit` input defaulting to false. The push trigger on `develop` is gone. `deploy.yml` passes `submit: true`. The job timeout is 240 minutes.
- **Teardown split (Task 1).** `marketplace-signing.sh teardown-signing` removes the keychain (restoring the search list), the installed profiles and every file `setup` wrote, and keeps `private_keys/`. `teardown` does the same and then removes the work folder. Both exit 0 when run again.
- **Client (Tasks 1 and 2).** `asc.py` restores `wait-build`, `ensure-version`, `attach-build` and `submit` from history (no `adp-id`) and adds `whats-new`. `ALLOWED` holds exactly eleven entries, matched with `re.fullmatch`, IDs limited to letters, digits and hyphens, with an argparse `identifier` type as a second guard. Every request goes through `Client.request`, so every call is a line in the call record.
- **What's New (Task 2).** `whats-new` reads the notes with `release_notes.read`, matches each localization with `altstore_languages.localized_value`, and refuses before writing anything when a locale has no section, when there are no localizations, when the notes file is missing or incomplete, or when a section is over 4,000 characters. The workflow checks the notes file before the API key is written (only with `submit` on) and fills What's New between ensuring the version and attaching the build.
- **Records (Task 3).** `20-08-SUBMISSION.md` and `REQUIREMENTS.md` carry dated 2026-11-26 amendments for DIST-18-03, which stays Complete.
