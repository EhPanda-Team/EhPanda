## Decisions and engineering resolutions

Owner decisions: D56 app-wide; D57/D58 management-oriented Library; D59 retire global layout; D60 independently remembered Frontpage, Popular, Toplists, Favorites, Search and Downloads; D61 aligned regular grid; D63 implementation authorized with Search A/B excluded; D64 common category navigation with distinct source groups. D62 selected workspace is already established and must be preserved.

Engineering resolutions approved by the orchestrator:
- Add independent Watched and History presentation scopes because those full lists also consumed the old global setting. DetailSearch shares Search's scope. These are compatibility completion, not additional owner decisions. No per-category, folder or toplist-period preferences.
- Migrate every formerly global-controlled scope from detail to row or thumbnail to grid. Downloads starts row. Fresh installs start row everywhere. Use the existing Setting schema migration mechanism, not a second live global value.
- Retain existing Favorites/Downloads stores at AppReducer level. LibraryFeature owns only Library navigation state and emits destination intent; it never owns duplicate gallery data, statuses or a duplicate download coordinator.
- Use one two-column NavigationSplitView at every size. Sidebar sections are Favorites and Downloads; detail contains the selected group's existing gallery navigation stack. The sidebar must not wrap itself in another NavigationStack. Native collapse handles narrow sequential navigation. Initial normal entry has no category selected and shows Library navigation; wide detail shows a localized selection prompt. Selection is remembered in scene state for subsequent tab entries.
- Keep existing download status sheet and reading cover. A permanent detail pane or native inspector conversion is not required by the selected design. Detail opening follows the app's existing window-size routing.
- Shared toolbar picker uses localized Row/Grid choices and typed symbols. It changes presentation only. Grid column count responds to local available width and scaled text, without changing the saved mode. Regular cards use a consistent portrait cover slot with aspect-fit media, aligned row starts and natural text reflow; larger text may reduce column count. No forced multi-column floor that clips AX text.
- Preserve query/sort/child path across presentation changes. Store visible gallery ID and accessibility focus outside the row/grid branch, restore the same ID when still present, and fall back to the nearest surviving gallery when data changed.
- Remove the obsolete global analytics parameter rather than misreporting a list-specific value as global. Tab analytics uses the closed Library case; existing content-level Favorites/Downloads signals keep their meanings. No category names, folder names or query text enter analytics.
