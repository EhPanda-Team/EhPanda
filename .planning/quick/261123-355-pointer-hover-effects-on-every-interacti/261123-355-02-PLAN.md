A. Scanner and fixtures (D-08). `AppPackage/Tests/AppToolsTests/PointerHoverScannerTests.swift` holds
`enum PointerHoverScanner` and `@Suite struct PointerHoverScannerTests` (the fixtures in <behavior>). The scanner works
on the file's UTF-8 bytes:
`static func preprocessed(_ source: String) -> String` returns an ASCII string of the same byte length with line
breaks kept, in three passes: (1) blanking: every byte of a comment (`//` to end of line; `/* */` nested) and of a
string literal from its opening to its closing delimiter (plain, `"""` multiline, raw `#"…"#`/`##"…"##` and raw
multiline, with `\(…)` / `\#(…)` interpolations tracked by paren depth so a nested string cannot end the outer one,
and blanked with it) becomes a space, and every non-ASCII byte becomes a space; (2) `#if`/`#elseif`/`#else`/`#endif`
evaluated line by line with a stack, blanking inactive branches and the directive lines; the condition grammar is
`!`, `&&`, `||`, parentheses, `true`, `false`, `os(X)` (true only for iOS), `canImport(X)` (false only for AppKit),
and every other identifier or call such as `DEBUG`, `targetEnvironment(…)` or `swift(…)` true; (3) each `#Preview`
followed (after an optional balanced `(…)`) by a `{` has that brace block blanked.
`enum SiteKind: String, CaseIterable, Sendable { case plainButtonStyle, plainButtonStyleInitializer,
onTapGesture, tapGesture, spatialTapGesture, buttonStyleConformance }`. `struct Site: Sendable { let kind:
SiteKind; let offset: Int; let passes: Bool }`. `static func sites(in processed: String) -> [Site]` finds:
`.buttonStyle(` + optional spaces + `.plain` + optional spaces + `)`; `.onTapGesture` not followed by an identifier
character; `PlainButtonStyle` + optional spaces + `()`; `TapGesture` and `SpatialTapGesture` as whole identifiers (the
bytes before and after are not identifier characters, which excludes `UITapGestureRecognizer`,
`onSingleTapGestureEnded`, and keeps `SpatialTapGesture` out of `TapGesture`); and `struct Name[<…>] : …{` whose
inheritance list contains `ButtonStyle` or `PrimitiveButtonStyle` as a whole identifier. A chain is read from a
`.member`: skip spaces and line breaks, read `.` + identifier, skip one balanced `(…)` if it follows on the same line,
then skip trailing closures (`{…}` on the same line, then any `label: {…}`), and repeat while the next non-space
character is `.`. For `.buttonStyle(.plain)` and `.onTapGesture` the chain starts at the site; for the three value
kinds walk outward through enclosing `(` (tracking depth, stopping at a `{` or `}` at depth 0) while each `(` is
directly preceded by `.identifier`, and start the chain at the outermost such member call; with no enclosing member
call start at the value's own postfix members after its `(…)`. A site passes when any member after the chain's first
is `interactiveHover`, `interactiveIconHover` or `cellRowHover`; a conformance passes when its brace-matched body
contains `.interactiveHover(`, `.interactiveIconHover(` or `.cellRowHover(`.
`static func setsIconTapShape(_ processed: String) -> Bool` detects `contentShape(` + `.interaction` + `,` +
`HoverTargetCircle` with optional whitespace. Allowlist evaluation is a pure function over `[Site]` per file and
`[HoverAuditAllowance]` returning the non-passing counts keyed `"<file>|<kind>"` and the reasonless entries, so the
fixture tests can check stale, missing and empty-reason entries without the live tree. Index bytes only after a
bounds check (this is a `*Tests.swift` file, but write guarded access anyway).
