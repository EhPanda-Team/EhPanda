A. Helper file `AppPackage/Sources/AppTools/InteractiveHover.swift` (D-01, D-02, D-03, D-06). `public import SwiftUI`
only (AppTools already has `.swiftlint.yml`; no macOS branch, D-01). Public API, exactly:
- `public enum InteractiveHoverEffect: Sendable { case highlight, lift }` with an internal computed `HoverEffect`
  (`.highlight` / `.lift`).
- `extension View`: `public func interactiveHover(_ effect: InteractiveHoverEffect, in shape: some Shape) -> some View`
  = a private `ViewModifier` that reads `@Environment(\.isEnabled)` and applies, on separate lines,
  `contentShape(.hoverEffect, shape)`, `hoverEffect(<effect>)`, `hoverEffectDisabled(!isEnabled)` (D-03 Disabled).
  `public func hoverShape(_ shape: some Shape) -> some View` = only `contentShape(.hoverEffect, shape)`; its doc
  comment says it is for a system-styled control whose own hover has the wrong shape, adds no effect of its own and
  exists so every hover shape in the app goes through this one vocabulary (D-05, D-06).
  `public func interactiveIconHover(clippedAt edges: Edge.Set = []) -> some View` = `contentShape(.interaction,
  HoverTargetCircle(clippedAt: edges))` followed by `interactiveHover(.highlight, in: HoverTargetCircle(clippedAt:
  edges))`; doc comment: the circle is the tap area and the hover area at once so they can never drift, and the
  view's frame does not change (D-03).
- `public struct HoverTargetCircle: Shape` with `public static let minimumDiameter: CGFloat = 44`, `public let
  clippedEdges: Edge.Set`, `public init(clippedAt edges: Edge.Set = [])`, `layoutDirectionBehavior` returning
  `.mirrors`, and `path(in:)`: diameter = max(44, rect.width, rect.height), a circle of that diameter centred on
  rect's midpoint; when `clippedEdges` is empty return the circle path; otherwise start from the circle's bounding
  rect and move each clipped side onto rect's own side (.leading -> minX, .trailing -> maxX, .top -> minY,
  .bottom -> maxY; geometry is written left-to-right and mirrored by `layoutDirectionBehavior`), and return the
  circle path's `intersection` with that rect's path. Doc comment: why 44, why a clipped side stops at the view's
  bounds (a neighbouring control), why the shape mirrors.
- `public struct HoverCapsule: Shape` with `public let horizontalOutset: CGFloat`, `public let verticalOutset:
  CGFloat`, `public init(horizontalOutset:verticalOutset:)`, path = `Capsule(style: .continuous).path(in:)` of rect
