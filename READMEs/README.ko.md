## 면책 조항
이 앱의 콘텐츠는 모두 E-Hentai에서 가져오며, E-Hentai 사용자가 올린 것입니다.

**E-Hentai 콘텐츠 이용에 따른 책임은 사용자 본인에게 있습니다.**

## 분석
EhPanda는 얼마나 많은 사람이 앱을 사용하는지, 어떤 기능이 중요한지 개발자가 파악할 수 있도록 익명 사용 데이터를 [TelemetryDeck](https://telemetrydeck.com)에 전송합니다. **앱을 처음 열 때 공유할 범위를 선택하기 전에는 아무것도 전송되지 않으며, 선택한 내용은 설정 → 일반 → 분석에서 언제든지 바꿀 수 있습니다.** 소스 코드로 직접 빌드한 앱과 포크 버전은 아무것도 전송하지 않습니다.

각 수준에서 전송되는 내용과 수집하지 않는 정보는 [개인정보 처리방침](https://ehpanda.app/ko/privacy/)에서 자세히 확인할 수 있습니다.
