## Installation
1. Lade die IPA-Datei von [Releases](https://github.com/EhPanda-Team/EhPanda/releases) herunter.
2. Installiere sie mit einem Tool wie [AltStore](https://altstore.io) auf deinem Gerät.

<sub>Erfordert iOS / iPadOS 27.0 oder neuer.</sub>

## Haftungsausschluss
Alle Inhalte dieser App stammen von E-Hentai und wurden von dessen Nutzern hochgeladen.

**Der Zugriff auf E-Hentai-Inhalte erfolgt auf eigene Gefahr.**

## Analyse
EhPanda sendet anonyme Nutzungsdaten an [TelemetryDeck](https://telemetrydeck.com), damit die Entwickler erkennen können, wie viele Menschen die App nutzen und welche Funktionen wichtig sind. **Es wird nichts gesendet, bevor du beim ersten Öffnen der App wählst, wie viel geteilt wird, und du kannst deine Wahl jederzeit unter Einstellungen → Allgemein → Analyse ändern.** Selbst kompilierte Versionen und Forks senden überhaupt nichts.

Was jede Stufe genau sendet und was nie erfasst wird, steht in der [Datenschutzerklärung](https://ehpanda.app/de/privacy/).
