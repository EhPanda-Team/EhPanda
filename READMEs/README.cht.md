## 分析
EhPanda 會向 [TelemetryDeck](https://telemetrydeck.com) 傳送匿名分析資料，讓維護者了解哪些功能重要。**此功能預設開啟。你可以隨時在「設定 → 一般 → 分析」中關閉。**

傳送的資料只是粗略描述使用情況：開啟了哪些頁面與面板；搜尋以特徵形式傳送（字詞數、是否使用標籤語法、關鍵字長度、結果數量的大致範圍），而非文字本身；每次閱讀以頁數與時間長度的區間表示；下載結果，例如完成或失敗；發生了哪類錯誤；以及隨每個事件一併傳送的六項 App 設定：畫廊網站、登入狀態、閱讀方向、雙頁模式、標籤翻譯與清單顯示模式。其中絕不包含畫廊的識別碼、權杖或標題，任何畫廊或頁面連結，搜尋關鍵字文字，標籤的值，使用者名稱，Cookie 或任何其他憑證，以及檔案路徑。

每個事件還會附帶 TelemetryDeck SDK 自動加入的一組標準技術資訊：裝置型號與架構，螢幕尺寸、縮放比例與方向，作業系統版本，App 版本與建置編號，是否為除錯或模擬器建置，你的語言、地區、文字排列方向與時區，以及該事件傳送時的日期與時刻。除此之外還包括你的系統外觀與輔助使用設定（淺色或深色模式、文字大小、粗體文字、減少動態效果、減少透明度、反相顏色、增加對比、不以顏色來區分），以及描述使用量的統計數字，例如首次開啟的日期、工作階段次數、使用過的天數與工作階段的長度。

事件會附帶 TelemetryDeck 內建的匿名安裝識別碼，該識別碼會在裝置上完成雜湊後才傳送，且 TelemetryDeck 不保留 IP 位址。此識別碼不會連結到你本人，並會在 iOS 重新產生裝置的供應商識別碼時重設，也就是同一開發者的所有 App 都被刪除時。資料的處理方式請參閱 [TelemetryDeck 隱私權政策](https://telemetrydeck.com/privacy)。

關閉「分享分析資料」後，上述所有事件以及隨其傳送的六項 App 設定都會停止傳送。但你的安裝仍會計入統計，讓維護者了解有多少人使用本 App；也就是說，匿名識別碼與上一段所述的技術資訊仍會在每個工作階段中傳送一次。關閉後傳送的資訊會大幅減少，但不會完全停止。

官方發行版在建置時會包含分析憑證，由發布工作流程從儲存庫密鑰中取得，因此除非你關閉該設定，否則會傳送上述事件。未包含這些憑證的建置不會傳送任何內容，無論該設定如何：從原始碼自行建置的版本以及 Fork 版本，都會因缺少憑證而關閉分析功能。
