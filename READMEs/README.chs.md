## 安装步骤
1. 从 [Releases](https://github.com/EhPanda-Team/EhPanda/releases) 下载 IPA 文件。
2. 用 [AltStore](https://altstore.io) 这类工具安装到你的设备。

<sub>需要 iOS / iPadOS 27.0 或以上版本。</sub>

## 分析
EhPanda 会向 [TelemetryDeck](https://telemetrydeck.com) 发送匿名使用数据，让维护者了解有多少人使用本应用以及哪些功能重要。**在你首次打开应用并选择分享多少之前，不会发送任何内容；之后可以随时在“设置 → 通用 → 分析”中更改。** 从源代码自行构建的版本和分支版本不会发送任何内容。

各级别具体发送哪些内容、哪些信息绝不收集，请参阅[隐私政策](https://ehpanda.app/zh-Hans/privacy/)。
