## 安装步骤
1. 在 [Releases](https://github.com/EhPanda-Team/EhPanda/releases) 取得 ipa 文件。
2. 使用 [AltStore](https://altstore.io) 这类软件将 ipa 文件安装到你的设备。

## 系统要求
请确保你的设备系统为 iOS / iPadOS 26.0 以上。

## 内容及其著作权
本应用程序中的内容均来自 E-Hentai，而 E-Hentai 的内容均为用户生成内容。

**本应用程序的用户需要自行承担访问 E-Hentai 内容的责任。**

## 分析
EhPanda 会向 [TelemetryDeck](https://telemetrydeck.com) 发送匿名分析数据，以便维护者了解哪些功能重要。**此功能默认开启。你可以随时在「设置 → 一般 → 分析」中关闭。**

发送的数据只是粗略描述使用情况：打开了哪些页面和面板；搜索以特征形式发送（词数、是否使用标签语法、关键词长度、结果数量的大致范围），而非文本本身；阅读会话以页数和时长的区间表示；下载结果，例如完成或失败；发生了哪类错误；以及随每个事件一同发送的六项应用设置：画廊站点、登录状态、阅读方向、双页模式、标签翻译和列表显示模式。其中绝不包含画廊的标识符、令牌或标题，任何画廊或页面链接，搜索关键词文本，标签的值，用户名，Cookie 或任何其他凭据，以及文件路径。

每个事件还会附带 TelemetryDeck SDK 自动添加的一组标准技术信息：设备型号与架构，屏幕尺寸、缩放比例和方向，操作系统版本，应用版本与构建号，是否为调试或模拟器构建，你的语言、地区、文字排列方向和时区，以及该事件发送时的日期与时刻。除此之外还包括你的系统外观与辅助功能设置（浅色或深色模式、文字大小、粗体文本、减弱动态效果、降低透明度、反转颜色、增强对比度、不使用颜色区分），以及描述使用量的统计数字，例如首次打开的日期、会话次数、使用过的天数和会话的时长。

事件会携带 TelemetryDeck 内置的匿名安装标识符，该标识符在设备上完成哈希后才会发送，且 TelemetryDeck 不保留 IP 地址。此标识符与你本人无关，并会在 iOS 重新生成设备的供应商标识符时重置，也就是同一开发者的所有应用都被删除时。数据的处理方式请参阅 [TelemetryDeck 隐私政策](https://telemetrydeck.com/privacy)。

关闭「共享分析数据」后，上述所有事件以及随其发送的六项应用设置都会停止发送。但你的安装仍会被计入，以便维护者了解有多少人在使用本应用；也就是说，匿名标识符和上一段所述的技术信息仍会在每个会话中发送一次。关闭后能被了解到的信息会大幅减少，但这并不意味着应用完全静默。

官方发行版在构建时会包含分析凭据，由发布工作流从仓库密钥中获取，因此除非你关闭该设置，否则会发送上述事件。未包含这些凭据的构建不会发送任何内容，无论该设置为何：从源码自行构建的版本以及各类分支仓库，都会因缺少凭据而关闭分析功能。
