## インストール手順
1. [Releases](https://github.com/EhPanda-Team/EhPanda/releases) から IPA ファイルをダウンロードします。
2. [AltStore](https://altstore.io) などのツールでデバイスにインストールします。

<sub>iOS / iPadOS 27.0 以降が必要です。</sub>

## 免責事項
このアプリのコンテンツはすべて E-Hentai から取得したもので、同サイトのユーザーが投稿しています。

**E-Hentai のコンテンツへのアクセスは、ご自身の責任で行ってください。**

## 分析
EhPanda は、アプリの利用者数とどの機能が重要かを開発者が把握できるよう、匿名の利用データを [TelemetryDeck](https://telemetrydeck.com) に送信します。**アプリを初めて開いたときにどこまで共有するかを選ぶまでは何も送信されず、選んだ内容は 設定 → 一般 → 分析 からいつでも変更できます。** ソースコードからビルドしたアプリやフォーク版は、何も送信しません。

各レベルで送信される内容と、収集しない情報について詳しくは、[プライバシーポリシー](https://ehpanda.app/ja/privacy/)をご覧ください。
