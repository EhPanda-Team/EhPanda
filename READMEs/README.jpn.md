## インストール手順
1. [Releases](https://github.com/EhPanda-Team/EhPanda/releases) から IPA ファイルをダウンロードします。
2. [AltStore](https://altstore.io) などのツールでデバイスにインストールします。

<sub>iOS / iPadOS 27.0 以降が必要です。</sub>

## 免責事項
このアプリのコンテンツはすべて E-Hentai から取得したもので、同サイトのユーザーが投稿しています。

**E-Hentai のコンテンツへのアクセスは、ご自身の責任で行ってください。**

## 分析
EhPanda は、アプリの利用者数とどの機能が重要かを開発者が把握できるよう、匿名の分析データを [TelemetryDeck](https://telemetrydeck.com) に送信します。**どこまで共有するかはアプリを初めて開いたときに選び、設定 → 一般 → 分析 からいつでも変更できます。選ぶまでは何も送信されません。** レベルは次の 3 つです。

- **最小限**：EhPanda がインストールされていることと、アプリの入手元だけを送信します。
- **基本**：「最小限」の内容に加え、アプリの利用頻度、使用している画面や機能、デバイスのモデルやアプリのバージョンなどの技術情報、発生したエラーの種類を送信します。
- **すべて**：「基本」の内容に加え、閲覧とダウンロードの状況、主な設定を送信します。

どのレベルでも、ギャラリーの識別子・トークン・タイトル、ギャラリーやページの URL、検索キーワードの文字列、タグの値、ユーザー名、Cookie を含む認証情報、ファイルパスが含まれることは一切ありません。

「最小限」では、インストールの通知をインストールごとに 1 回だけ送信します。含まれるのはアプリの入手元（GitHub、AltStore、SideStore、AltStore PAL、EhPanda Beta のいずれか。EhPanda が公開していないビルドは「source」）と、このインストールのために生成したランダムな識別子だけで、デバイスに関する情報は含まれません。公式のダウンロードにはそれぞれ公開先が記録されているため、この通知でわかるのはどのダウンロードを使っているかで、どの方法でインストールしたかではありません。TelemetryDeck の SDK は起動しません。

「基本」では、同じインストールの通知に加えて TelemetryDeck の SDK を起動し、次の情報を送信します。
- アプリの利用頻度：SDK 自身のセッション通知と集計値（初回に開いた日付、セッションの回数、利用した日数、セッションの長さなど）
- 使用している画面や機能：開いたタブやホームのセクション、フィルタとクイック検索のパネル、保存した検索、タグのタップ（タグの名前空間のみで、値は送信しません）、そして検索は語句ではなく特徴（単語数、タグ構文を使ったかどうか、キーワードの文字数、結果件数のおおよその範囲）として、さらに初回起動の画面を完了したことと選んだレベル、設定でのレベルの変更（変更前と変更後のレベル）、コメントのモデレーション（ブロック、ブロックの解除、非表示のコメントの表示、投稿時の警告への回答、通報の結果：送信済み、失敗、利用不可、サイトで開いた）
- すべてのイベントに添えられるアプリの入手元
- 発生したエラーの種類（ログインの失敗と Cloudflare のチャレンジを含む）
- SDK が毎回のイベントに自動的に付加する標準的な技術情報：デバイスの機種とアーキテクチャ、画面のサイズ・倍率・向き、OS のバージョン、アプリのバージョンとビルド番号、デバッグビルドやシミュレータビルドかどうか、言語・地域・文字の方向・タイムゾーン、イベントが送信された日付と時刻、そしてシステムの外観とアクセシビリティの設定（ライト／ダークモード、テキストサイズ、文字を太くする、視差効果を減らす、透明度を下げる、色を反転、コントラストを上げる、カラー以外で区別）

「すべて」では、さらに開いたギャラリー（カテゴリと名前空間ごとのタグ数のみで、ギャラリーそのものは送信しません）、ページ数と時間の範囲として表した閲覧セッション、ダウンロードの結果（完了、失敗など）、そして毎回のイベントに付随する 5 つのアプリ設定（ギャラリーサイト、ログイン状態、読む方向、見開き表示、タグ翻訳）の現在の値を送信します。

「基本」と「すべて」では、イベントに TelemetryDeck に組み込まれた匿名のインストール識別子が付きます。これはデバイス上でハッシュ化されてから送信されます。この識別子はあなた個人と結び付くものではなく、iOS がベンダー識別子を再生成したとき、つまり同じ開発者のアプリをすべて削除したときにリセットされます。TelemetryDeck は IP アドレスを保持しません。データの取り扱いについては [TelemetryDeck のプライバシーポリシー](https://telemetrydeck.com/privacy) をご覧ください。

公式リリースは、リリースワークフローがリポジトリのシークレットから取得した分析用の認証情報を含めてビルドされるため、選んだレベルで許可された内容を送信します。その認証情報を含まないビルドからは、どのレベルを選んでも何も送信されません。ソースから自分でビルドした場合やフォークでは、認証情報がないため分析は無効になります。
